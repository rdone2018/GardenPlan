# GardenPlan
Plannig and monitoring garden

Ideas:
Database of gardens in system (multiple gardens possible)
- define location of garden -> Weather + calculation of Sunshine times
- Mesh definition, how big garden is = how many cells with x height

- for every garden:
   - Database with vegetables (can be shared between Gardens)
      - type
      - conditions (shadow, wattered,..)
      - Life span
      - connection to Calendar
      - eShops URL
      - Price
      - Web data sync - details about vegetable, recommendation about other vegetables alongside (or vegetables not compatible to be near)
   - Database of costs
      - vegetable prices
      - works delivered and paid
   - Reports
      - vegetables (numbers, increase per year,...)
      - costs
   - Mesh view for garden with picture/map background
      - allow drag&drop vegetable to cells 
      - view cell content - breif + on click all details (incl. photos, links , calendar and data downloaded from Web)
      - editable cells - add, change, delete, move from cell to cell
      - control content of cell
   - Contacts DB for garden (can be shared between Gardens)
      - 3rd party gardener companies
      - architects
      - technical support (e.g. wattering)   
   - Calendar per every vegetable with reminders
      - deploy vegetable
      - care vegetable
      - de-deploy vegetable
      - hummus timer
      - works planned/delivered
           - what, who, how much
   - Calendar per Garden tech
      - deploy- spring
      - care
      - winter
   - Garden Tech - monitoring & control (via mesh map)
      - Watering
      - Garden lights
      - Mowers
      - Cameras
   -
